# Feature overview

| Area | Purpose | Interpretation / caveat |
|---|---|---|
| Inventory template | Create project-specific Excel process sheets | Data collection, not independent verification |
| Import Data | Review process summaries and workbook content | Depends on supplied inventory |
| PFD / System Model | Visualize processes, map and review connections | Graphical route is not scientific approval |
| LCI Data Table | Inspect records, units, sources and corrections | Reported and estimated values must be distinguished |
| Data Quality | Surface missing quantities and unsupported conversions | Empty issues list does not prove completeness |
| Mass Balance | Residuals, calculation tables, diagrams | Provisional pass does not establish closure |
| Energy Balance | Organize energy carriers and estimates | Thermodynamic inputs may be missing |
| Heat Integration | Explore potential heat recovery | Optional and data-dependent |
| Communication Export | Partner queries, replies and exports | Queries should be source-specific |
| System Scaling | Reference-basis and scenario adjustment | Capacity and yield assumptions need evidence |
| System Integration | Combine systems, connect streams, review integrated PFD | Composition, allocation and boundaries require review |

Feature availability and output formats must be confirmed against the final installer build. This document describes the project workflow, not completed acceptance testing.
